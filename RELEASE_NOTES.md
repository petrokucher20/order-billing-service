# Нотатки до релізу

## v1.1.0

### Added (Додано)
- Спеціальна базова ставка доставки 80.0 для міста Київ.
- Явний параметр ставки податку `tax_rate` (за замовчуванням 0.20) у функції `process_standard_invoice`.

### Changed (Змінено)
- Коефіцієнт доставки за вагу збільшено з 12.0 до 15.0 за кілограм.
- Модуль білінгу відрефакторено: перехід від Common, Control та Stamp Coupling до Data Coupling.

### Breaking Changes (Несумісні зміни)
- Змінено сигнатури функцій розрахунку: `calculate_delivery_cost(city, weight_kg)` тепер приймає рядок із назвою міста замість об'єкта `CustomerProfile`.
- Функцію `process_invoice(..., mode_flag)` видалено та замінено двома окремими функціями: `process_standard_invoice(...)` і `process_tax_exempt_invoice(...)`.
- Видалено глобальну змінну `GLOBAL_TAX_RATE` та параметр `mode_flag`; ставку податку тепер потрібно передавати явно як аргумент.
